# kotlin-practice

Дни 01–05 плана `plan_kotlin_4.xlsx`. Один пакет = один день.

- Задачи: `src/main/kotlin/dayNN_*/Tasks.kt` — заменить `TODO()` на решение.
- Проверка: `./gradlew test --tests "day01_basics.*"` (или кнопка ▶ у класса теста в IntelliJ).
- Тесты: `src/test/kotlin/dayNN_*/TasksTest.kt` — читать как ТЗ.

JDK: 21+ (в IntelliJ: File → Project Structure → SDK). Первый запуск скачает Gradle в `~/.gradle`.
